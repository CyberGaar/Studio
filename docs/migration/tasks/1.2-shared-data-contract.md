## Security design

- `@cybergaar/data-contracts` is the versioned, publishable contract; it does not contain a generated Prisma client.
- `cybergaar_backend_migrator` is a `NOLOGIN` group role and the only role granted schema creation.
- Application login identities are environment-owned and receive membership in exactly one `NOLOGIN` application group role.
- Backend is the only all-table application role. AI, Fleet, Viewer, and database-worker contracts enumerate tables explicitly.
- AI receives a column-scoped update grant for `users.dashboard_view`; it does not receive general `users` writes.
- Generated role SQL is reproducible from the JSON contract, and the contract pins the canonical Prisma schema SHA-256.
- Table grants do not replace user authorization or tenant checks in application services.
